# Fruit Match

Primeira versão jogável do jogo de combinar frutas.

## Como jogar
- Toque em uma fruta do tabuleiro para enviá-la à reserva.
- Ao juntar três frutas iguais, as três são removidas automaticamente.
- A reserva tem cinco espaços. Se ficar cheia, a partida termina.
- Use desfazer para voltar uma jogada ou embaralhar para reorganizar as frutas.

## Estrutura
- `index.html`: tela e estrutura do jogo.
- `css/style.css`: identidade visual e layout responsivo.
- `js/game.js`: regras e funcionamento da partida.

## Testar
Abra `index.html` em um navegador ou publique o repositório com GitHub Pages.

Esta é a base inicial. Conta, amigos, rankings online, fases com objetivos variados e integração com anúncios serão desenvolvidos em etapas posteriores.
